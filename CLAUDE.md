# CineMosaic

One still from the middle of every shot of a cut, laid out on one sheet (contact sheet). Shared rules: `~/.claude/skills/moe-apps/SKILL.md`.

## Decisions (user, 2026-11-20)
- Two sources: (a) Media Composer bin + Avid MediaFiles volumes, (b) master file + cut list.
- Cut lists: EDL (CMX3600), FCP7 XML, FCPXML, AAF.
- Shot = what is visible: at every moment the topmost video track with a clip wins (`Timeline::shots`); a clip partly covered from above gives two shots. Generators/titles count as see-through.
- Still = middle frame of the shot: `start + len / 2` in record frames. Master mode: frame in master = record frame − master start TC (from ffprobe).
- Sheet fields: tabs Source / Sheet / Frame line / Headline. Width × height always shown; the Paper list fills it (`show_paper`), editing it picks the matching size or Custom (`size_edited`, ±0.6 mm). Unit mm/px (`px-units`, `switch_unit`) is only for the paper size; margin (may be negative: stills run off the page), gap, frame line thickness + distance, headline X/Y and its space are always px of the sheet (via dpi; user 2026-11-22); type size pt. All whole numbers (`whole()`).
- Sheet always full (user 2026-11-21): `timeline::fill` – cells left in the grid (cols × rows − shots, never more than one row) go to the longest shots (tie: earlier), which give two stills instead of the middle: `start + len/3` and `start + 2·len/3`; cut order kept. `picks()` plans it for the current sheet; grid(cells) = grid(shots), so filling never changes the grid. App keeps stills per `Pick` (shot, `Part`); a sheet change after grabbing shows grey cells and the button "Grab N missing stills" grabs only those (each grab its own folder grab-N); with nothing missing the button grabs everything again. Bin mode plans the first grab at 16:9 until a still gives the real aspect.
- Projects (user 2026-11-21): package `<name>.cinemosaic` (`src/project.rs`: project.json + stills/NNNNN.png, written to `.part` then swapped, old kept as `.old` until the new one is in place; UTI io.github.moritz-poth.cinemosaic.project conforms to com.apple.package, declared in build-mac-app.sh). Keeps source paths, sequence, volumes switched off, look (= preset JSON), headline text, shots, stills with their media file + frame. Menu File (Slint MenuBar in SheetWindow, every window; settings/manual forward to the front project window): New ⌘N = new window, Open… ⌘O, Open Recent (recent.txt, 10), Close Window ⌘W, Save ⌘S, Save As… ⇧⌘S. One window per project (user 2026-11-21): `WINDOWS` + `STATES` (state per `win-id`, `with_state(app, …)`), `FRONT` (key window, tracked in the chrome timer; menus of other windows and the app menu act on it), `new_window()` (cascaded 28 pt) / `wire_shared()` / `wire_window()` / `close_window()` (asks, drops state, removes cache `window-<id>`); `open_project_in`: already open → front, empty window takes it, else new window. Preview renderer per window (`State.renderer`). Language is set in `new_window` (Slint ignores it before a window exists). Last window closed = app quits. Open: stills shown at once, then the source is read again (`Carry` → `adopt_carry` in load_source/load_bin): equal `Shot`s keep stills, others grey; unreadable source = saved state, grabbing off. `State.done` (media file, frame) → still: grab reuses frames instead of grabbing again. Unsaved check = `snapshot()` compare (no project: any stills); asked on window close/Quit (every window) (`applicationShouldTerminate:` and `application:openURLs:` added to winit's `WinitApplicationDelegate`, `mac_app`). Tested 2026-11-21 with a temp hook (save, new, changed EDL → 1 missing → 1 frame grabbed, master missing → saved stills); Finder double-click NOT tested yet.
- Drag & drop (user 2026-11-23): files from the Finder onto a project window. Slint has no external file drop, so `wire_drop` uses the winit event filter (`slint` feature `unstable-winit-030`, ONE filter per window: HoveredFile → `drop-hover` overlay with file icon, HoveredFileCancelled, DroppedFile once per file → batched with a zero timer → `take_dropped`). Endings `LIST_EXT` (edl/xml/fcpxml/aaf) = cut lists, other files = masters via `add_files` (shared with Add…), folders skipped; a bin window switches to master mode; ignored while state 1 (overlay says wait). Tested with a temp hook calling `take_dropped` + snapshot; a real Finder drag only by the user.
- Several masters (user 2026-11-21): `State.masters` (path + ffprobe info) and `lists`, added with Add… (several files), removed with the × (`FileRow`); `pairs()`: master + cut list with the same file stem (case ignored); files without a partner are named in the error line; shots of all pairs one after the other, `Shot.key` = index of its master in master mode (unused there before), grab runs `master_jobs` per master. Project: `masters`/`lists` (old `master`/`list` read). Headline font: kept by name (`font_wanted`, applied once the font list is loaded – before, a project opened during font loading lost it); missing font → dialog naming it, then Helvetica Neue (`apply_font`). Font list: no blue focus frame / row.
- Scene detection (user 2026-11-21): "Detect cuts" below the cut lists (enabled while a master has neither list nor detection, `can-detect`) runs `frames::detect_cuts` (ffmpeg `scale=320:-2,scdet=threshold=10`, always the whole file) per master in a thread with the window's `gate`. Result `State.detected: (master, [0, shot starts…, frame count])`, listed as "Reel1.mov – N shots detected" (× = `remove-list` index past `lists`), turned into a timeline at the master's timecode (`detected_timeline`); a cut list of the same name wins (`CutSource`). Film range PER MASTER (user 2026-11-22, per master since 2026-11-23): Start / End fields under each master row (`masters-shown: [MasterRow{name, from, to}]`) = that master's timecodes, kept in `State.films` by master path (survives remove + add), applied in `load_source` to cut lists AND detected cuts (`within`, clips cut at the edges), right when a field loses focus (`film-changed(i, from, to)`, reload only if changed), saved in the project as `films: [(path, (from, to))]`; an old project's single `film` is read and given to every master. TC typing uses that master's own rate (`tc-edit(i, …)`, `last_frame(app, i)`). The fields are `TcField` with the logic in `src/tc.rs` (`tc_edit`: click a part → two digits replace it and move on, ↑↓ ←→; double-click/⌘A/Tab = whole timecode filled from the right like Avid, Backspace empties; ⌘V `tc_pasted`).
- Sheet: paper Custom, DIN A0–A6 or social media sizes + dpi, margin, gap; grid automatic (largest stills) or fixed columns; block centred. Frame line, headline, crop marks: see Sheet design.
- Output: PNG, TIFF, JPEG (dpi stored in the file), PDF (page = paper size).
- Stack: Rust + Slint (`ui/app.slint`); bin reading from MediaFiles Check's `avb.rs`. Frames via ffmpeg/ffprobe (bundled next to the binary, else Homebrew).

## Layout
- `src/timeline.rs` model + timecode (`Item.key` / `Shot.key` + `item_start` let bin mode find the component again), `edl.rs`, `fcp7.rs`, `fcpxml.rs` readers, `frames.rs` ffprobe/ffmpeg, `layout.rs` grid + render, `export.rs` files, `lib.rs` `read_cut_list`, `grab_stills` (4 parallel, `Gate` pause/cancel); while a run works (state 1) the Source tab controls are disabled (`enabled` on Dropdown/CheckDropdown/MenuButton/FileRow/TcField/Switch), every new gate cancels the old one, `clear_source` cancels, a grab result whose gate is no longer `st.gate` is dropped, `grabs` is never reset and a fresh grab deletes only the other `grab-N` folders (bug 2026-11-23: "could not open file …/grab-2/0087.png" after source changes during grabbing), `main.rs` test CLI.
- `src/app.rs` + `ui/app.slint`: window 1573 × 920 default (side column 380 px; its tab content scrolls when the window is too low, preview right). `app.rs` wires each window by job: `wire_source`, `wire_sheet`, `wire_design`, `wire_presets`, `wire_window` (File menu); `src/presets.rs` presets, `src/tc.rs` timecode fields, `src/mac.rs` everything AppKit (colour panel, app menu, app delegate, windows). State per window (`STATES`/`with_state`); stills in `~/Library/Caches/CineMosaic/stills-<pid>` (`clean_stills` at start/quit), 480 px copies in memory for the preview. An unreadable field turns red and the preview keeps its last good state.
- Screenshots: `screencapture -l` gave white images; a temp hook that calls `app.window().take_snapshot()` and quits works (removed again, re-add when needed).
- `tests/master.rs` proves the exact frame on a generated master (pixel colour = frame number).

## Picture format
`layout::PICTURE` = 9 film formats (4:3, 1.66, 16:9, 1.85, 1.9, 2, 2.35, 2.39, 2.4); `picture` 0 = Full frame, 1–9 film, 10 = Custom. Width : height is ONE field `aspect` ("2.39:1", "9:16"), filled by the menu (`show_picture`), typing picks the matching format or Custom (`picture_edited`); presets keep the typed `aspect`. Full frame shows the name the film world uses (`layout::nominal`, within 0.006: DCI Scope 2048 × 858 = 2.387 → 2.39:1, container 1.896 → 1.9:1, 1920 × 800 → 2.4:1; user 2026-11-22). `layout::crop` cuts the still around its centre when the sheet is drawn; stills on disk stay full frame. Paper menu = `SectionDropdown`: Custom, "DIN" A0–A6, "Social media" `layout::SOCIAL` px sizes (a social size switches the unit to px). Bin: several sequences (`CheckDropdown`, `seq_on`, project `chosen` by name). Export with missing stills asks Save Anyway / Cancel.

## Bin mode (2026-11-20)
- `src/avb.rs`: every object that starts like a component is read generically (0x02 0x01 = clip with length, 0x02 0x08 = track group with length + tracks), so unknown classes keep positions right. Parsed specially: SEQU, SCLP, TCCP (start TC), CMPO (mobs), TNFX (cut point), SLCT (selected angle = index into tracks), SPED (speed num/den). `Bin::pieces` = sequence pieces with transitions cut at their cut point (the next component runs under the transition: `raw` start). `Bin::resolve` follows a frame down: sequence → piece, effect → first input that shows media, selector → selected track, motion effect → offset × num/den, source clip → mob (this bin, else the project's other bins) → same track number + media kind, until a file mob (`Hit::Media`). Filler / empty effects = `Hit::Empty` = see-through (left out of the timeline).
- `src/bin.rs` `BinCut`: picture tracks of the sequence → `Timeline` (positions incl. the sequence's start TC); the project's other bins are read only if a clip is missing (project = nearest folder above with an .avp, Attic skipped). `jobs()` resolves each shot's middle, then `media::locate` finds the files.
- `src/media.rs`: msmFMID.pmr reader + MXF header reader copied from MediaFiles Check; `locate` uses the pmr names first, headers only for unlisted files while something is still missing. `volumes()` = /Volumes/* with "Avid MediaFiles/MXF" (UI polls every 2 s, switches per volume).
- Checked on the MediaFiles Check test lab (`~/MFC-Testlab/golden`, read only): 5 sequences, DNxHD OP-Atom frames grabbed (60 stills in 3 s); AMA sequence → "media file not on the chosen volumes" (linked files are not in Avid MediaFiles). Transitions, motion effects, multicam: unit tests only (the lab has none).
- AMA / linked media (user 2026-11-20): FILE/WINF locators are read (path, POSIX ext 0x01, UTF-8 ext 0x02); the path sits on the source mob BELOW the AMA file mob (file mob: CDCI + MSML locator, no path). `Bin::linked` returns that path with the FILE MOB's frame – the clip below carried start 1 for a 25-frame .mov (would push past the end). `bin::linked_file` accepts POSIX, file:// URLs and old "Volume:dir:file" paths. Checked: AMA sequence of the test lab, 10 stills from the .mov files (frame offset not proven, all lab clips look alike).
- Not handled yet: titles/keys on upper tracks count as visible (they resolve to media), sequence edit rate ≠ media rate is scaled but untested.

## Sheet design (user 2026-11-20, second round)
- Stills COVER their cell (scaled to fill, overhang cut around the centre) – the old fit-with-aspect left 1 px white lines at gap 0 and shifted cells; test `no_white_between_stills_at_gap_zero` uses odd sizes.
- `layout::Sheet` has `trim` (trim area of an aspect inside the paper, 12 mm room for crop marks: 3 mm off the corner, 6 mm long, 0.1 mm), `line` (width, inset from the trim edge, colour) and `headline` (text, `fonts::Face`, pt size, colour, top/bottom × left/centre/right). `Sheet::plan` places everything: headline centred on the line (without a line at the line's inset), left/right headline 8 mm in from the corner, the line breaks 2 mm around the text, the grid area keeps 2 mm clear of line and headline whatever the margin.
- Text: `src/fonts.rs` (fontdb: installed families for the menu, best face for bold/italic; missing bold = strokes widened, missing italic = slanted 0.2), drawn with ab_glyph in pt (em) sizes at the sheet's dpi.
- Texts (user 2026-11-23, tab "Text", was "Headline"): `layout::Sheet.texts: Vec<Headline>` (one element each; several lines with \n, `lines` = left/centre/right inside the box, `Plan.texts: Vec<Placed{i, rect, lines:(x, baseline), scale}>`), every text breaks the frame line (`fill_except` with several holes) and can keep stills out (`Grid.keep_out: Vec<Rect>`). UI (rebuilt 2026-11-23 after user feedback: typing lost focus after every letter and scrubbing stopped, because the list was rebuilt on every refresh; and several open at once / all closed wanted): `texts: [TextRow]` model (struct with every field + `open`, `title`, `font-name`), fields bound two-way to the row (`text <=> t.size`), Rust changes rows IN PLACE (`set_text_rows` / `with_text_row` compare and `set_row_data`; only a new count replaces the model) – never replace the model on refresh. `text-active` = last touched (dragged in the preview, named by `invalid`, which only marks fields of the active row). `row_style`/`style_row`/`default_row` (presets.rs) convert rows ↔ style JSON; `resolve_fonts` matches `font-name` to the list (missing font named once). `text_from` parses a style (errors name the field; only the active text reports them, another with a bad value is skipped); `text_index` maps drawn texts to rows. Tested with synthetic pointer/key events: typing keeps focus, scrub 24→54 while held, toggles, preset round trip. Preview: `text-boxes` (faint frames, click opens), open text draggable as before. Presets keep `texts: [style…]` + `global-angle`, no words (user); old flat head-* keys = one style. Projects keep `texts: [words]` (old `headline` read).
- Drop shadow (user 2026-11-23, "complete like Photoshop"): `layout::Shadow` blend (14 modes, `Blend::mix`), colour (shares the text palette, colour k 3), opacity, angle (light direction; shadow offset (-cos, +sin)·distance; Use global light = sheet-wide `global-angle`), distance, spread (dilate size·spread, blur the rest with 3 box passes), size, `Contour` (10 presets as curves, anti-aliased smooths the table), noise (fixed per-pixel hash), knock out (text hides its shadow). Drawn from the text's coverage mask (`text_mask`) under the text. Defaults Multiply, black, 75 %, 120°, 12 px, 0 %, 18 px.
- Photomosaic (user 2026-11-23: stills may repeat with a minimum distance, 1–5 stills per shot, main picture = file / drop / click on a still): `src/mosaic.rs` (`features` = 3 × 3 Lab pattern, `target_features`, `assign` greedy row by row: best Lab distance × (1 + 0.04·uses), stills within `repeat` tiles skipped while another is possible). `layout::Mosaic {target, cols, tiles, tint, overlay}` in `Sheet.mosaic`: own grid (cols × `rows(aspect)` so the block has the target's format, NO gap, no keep_out), `draw_mosaic` scales each still once, shifts its mean towards the tile's target mean (tint) and blends the target over (overlay). `Sheet.spread` = stills per shot while the mosaic is on (also before a target exists, so one grab fetches them) → `timeline::spread` with `Part::Of(k, n)` (project "k-of-n"). App: `read_mosaic` (fields Sheet tab, `mosaic-*`, presets keep them), `State.feats` (per Pick from the 480 px copies, cropped to the format, cleared when the copies change) + `mosaic_plan` cache keyed by what it depends on; `page_clicked` (Sheet tab, mosaic on, click not drag) takes the still under the mouse; `take_dropped` sends pictures (`IMAGE_EXT`) to the mosaic; target ≤ 3000 px; projects keep it as mosaic.png. Tested 2026-11-23 with a hue-cycling test master + Mandelbrot target (temp hook): plan 90 ms, A4 export 1.2 s.
- Frame line `Pattern` (Single, Double, Thick–thin, Thin–thick, Thin–thick–thin, Two close + one apart; `PatternPicker`). Headline hangs at one of 9 anchors of the trim area (`AnchorPicker`) moved by X/Y px; every line strand breaks only where the text box (+2 mm) covers it (`fill_except`). Headline space `pad_mm` [top, right, bottom, left] (UI px, default 24): top/bottom headlines keep the stills that far away; `wrap` ("Stills around the headline"): cells touching text + space stay empty (`Grid::keep_out`), the grid grows until `slots()` ≥ stills, `picks` use `slots()`. Preview on the Headline tab: drag the headline (hit area stays put, frame follows X/Y), grid in % of the trim area (preview only), centre ticks turn green on a grid line (±0.6 px), dragging snaps within 6 screen px.
- Colours: `ColorRow` = 5 colour presets per frame line / headline / sheet background (settings.txt lines 5–7, shared by all windows; `color_of`/`set_color`/`slot_of` by k 0/1/2). Background (user 2026-11-23, Sheet tab, preset key `bg-color`): `Sheet.background` fills the page, with crop marks the trim area + 3 mm bleed (paper beside the marks stays white); a click takes the preset, a click into the hex field opens the macOS colour panel (`mac::color_panel`, polled) whose colour becomes the chosen preset (saved when the panel closes). Font: `FontDropdown` (popup `FontList`, ↑/↓ open or closed, letter jump). Default orientation landscape.
- Bin mode: Sequence menu starts with "All sequences" (default) = every sequence of the bin in natural name order (`bin::natural`), shots one after the other; `BinCut.timelines`, `BinCut::shots()`. Bin-mode UI tests must not run with the 2 s volume poll – it swaps the test volumes for the user's real ones (happened twice); test bin mode with the CLI.
