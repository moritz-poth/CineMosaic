# CineMosaic

One still from the middle of every shot of a cut, laid out on one sheet (contact sheet). Shared rules: `~/.claude/skills/moe-apps/SKILL.md`.

## Decisions (user, 2026-11-20)
- Two sources: (a) Media Composer bin + Avid MediaFiles volumes, (b) master file + cut list.
- Cut lists: EDL (CMX3600), FCP7 XML, FCPXML, AAF (AAF still to do).
- Shot = what is visible: at every moment the topmost video track with a clip wins (`Timeline::shots`); a clip partly covered from above gives two shots. Generators/titles count as see-through.
- Still = middle frame of the shot: `start + len / 2` in record frames. Master mode: frame in master = record frame − master start TC (from ffprobe).
- Sheet fields (user 2026-11-21): tab "Frame line" (was "Line"). Width × height always shown; the Paper list fills it (`show_paper`), editing it picks the matching A size or Custom (`size_edited`, ±0.6 mm; also after a dpi change), Orientation swaps the two fields – the fields are the truth, no swap when reading. Unit mm/px (`px-units`) for every length: paper, margin, gap, line thickness + distance, headline X/Y; type size stays pt; switching converts all fields via dpi (`switch_unit`), A sizes exactly. All these fields and the type size are whole numbers (`whole()`; decimals = invalid, old presets rounded on load, line thickness ≥ 1 → default 1 mm). Sheet info line no longer shows the sheet's px size.
- Sheet always full (user 2026-11-21): `timeline::fill` – cells left in the grid (cols × rows − shots, never more than one row) go to the longest shots (tie: earlier), which give two stills instead of the middle: `start + len/3` and `start + 2·len/3`; cut order kept. `picks()` plans it for the current sheet; grid(cells) = grid(shots), so filling never changes the grid. App keeps stills per `Pick` (shot, `Part`); a sheet change after grabbing shows grey cells and the button "Grab N missing stills" grabs only those (each grab its own folder grab-N); with nothing missing the button grabs everything again. Bin mode plans the first grab at 16:9 until a still gives the real aspect.
- Projects (user 2026-11-21): package `<name>.cinemosaic` (`src/project.rs`: project.json + stills/NNNNN.png, written to `.part` then swapped, old kept as `.old` until the new one is in place; UTI io.github.moritz-poth.cinemosaic.project conforms to com.apple.package, declared in build-mac-app.sh). Keeps source paths, sequence, volumes switched off, look (= preset JSON), headline text, shots, stills with their media file + frame. Menu File (Slint MenuBar in SheetWindow, every window; settings/manual forward to the front project window): New ⌘N = new window, Open… ⌘O, Open Recent (recent.txt, 10), Close Window ⌘W, Save ⌘S, Save As… ⇧⌘S. One window per project (user 2026-11-21): `WINDOWS` + `STATES` (state per `win-id`, `with_state(app, …)`), `FRONT` (key window, tracked in the chrome timer; menus of other windows and the app menu act on it), `new_window()` (cascaded 28 pt) / `wire_shared()` / `wire_window()` / `close_window()` (asks, drops state, removes cache `window-<id>`); `open_project_in`: already open → front, empty window takes it, else new window. Preview renderer per window (`State.renderer`). Language is set in `new_window` (Slint ignores it before a window exists). Last window closed = app quits. Open: stills shown at once, then the source is read again (`Carry` → `adopt_carry` in load_source/load_bin): equal `Shot`s keep stills, others grey; unreadable source = saved state, grabbing off. `State.done` (media file, frame) → still: grab reuses frames instead of grabbing again. Unsaved check = `snapshot()` compare (no project: any stills); asked on window close/Quit (every window) (`applicationShouldTerminate:` and `application:openURLs:` added to winit's `WinitApplicationDelegate`, `mac_app`). Tested 2026-11-21 with a temp hook (save, new, changed EDL → 1 missing → 1 frame grabbed, master missing → saved stills); Finder double-click NOT tested yet.
- Several masters (user 2026-11-21): `State.masters` (path + ffprobe info) and `lists`, added with Add… (several files), removed with the × (`FileRow`); `pairs()`: master + cut list with the same file stem (case ignored); files without a partner are named in the error line; shots of all pairs one after the other, `Shot.key` = index of its master in master mode (unused there before), grab runs `master_jobs` per master. Project: `masters`/`lists` (old `master`/`list` read). Headline font: kept by name (`font_wanted`, applied once the font list is loaded – before, a project opened during font loading lost it); missing font → dialog naming it, then Helvetica Neue (`apply_font`). Font list: no blue focus frame / row.
- Scene detection (user 2026-11-21): "Detect cuts" below the cut lists (always shown in master mode – user 2026-11-22; enabled while a master has neither list nor detection, `can-detect`) runs `frames::detect_cuts` (ffmpeg `scale=320:-2,scdet=threshold=10`, `-progress pipe:1` for frames, ffprobe duration for the total; whole file decoded) per master in a thread with the window's `gate`. Result `State.detected: (master, [0, shot starts…, frame count])`, listed after the cut lists as "Reel1.mov – N shots detected" (× = `remove-list` index past `lists`), turned into a one-track timeline at the master's timecode (`detected_timeline`); a cut list of the same name wins (`CutSource`). Project field `detected`. Range (user 2026-11-22, against opening/end titles): fields `detect-from`/`detect-to` = master timecodes (empty = start/end, not saved in the project), turned into file frames per master; ffmpeg input `-ss`/`-to` (quarter frame early, like grab) reads only that part, the first shot starts at `from`; a master wholly outside → "no picture between start and end". The two fields are `TcField` (user 2026-11-22): a FocusScope, not a TextInput – keys go to Rust `tc_key` (digits added at the right, Avid-style fill from the right, max 8, leading zeros give way, Backspace/Delete drops the last, all else ignored; all zero = empty); empty shows 00:00:00:00 in `Theme.disabled`. A TextInput reformatted in `edited` put the cursor back to the start (tried, failed). Tested via temp hook with a 3-shot ffmpeg test file (cuts 75/125 exact, save/open in a new window, ×); not tested on a real film (speed, dissolves).
- Sheet: Custom or DIN A0–A6 + dpi, margin, gap; grid automatic (largest stills) with optional fixed column count; block centred. Frame line, headline, crop marks: see Sheet design.
- Output: PNG, TIFF, JPEG (dpi stored in the file), PDF (page = paper size).
- Stack: Rust (Slint UI to come, like MediaFiles Check); bin reading will reuse `src/avb.rs` from MediaFiles Check. Frames via ffmpeg/ffprobe (bundled next to the binary, else Homebrew).

## Bin mode (2026-11-20)
- `src/avb.rs`: every object that starts like a component is read generically (0x02 0x01 = clip with length, 0x02 0x08 = track group with length + tracks), so unknown classes keep positions right. Parsed specially: SEQU, SCLP, TCCP (start TC), CMPO (mobs), TNFX (cut point), SLCT (selected angle = index into tracks), SPED (speed num/den). `Bin::pieces` = sequence pieces with transitions cut at their cut point (the next component runs under the transition: `raw` start). `Bin::resolve` follows a frame down: sequence → piece, effect → first input that shows media, selector → selected track, motion effect → offset × num/den, source clip → mob (this bin, else the project's other bins) → same track number + media kind, until a file mob (`Hit::Media`). Filler / empty effects = `Hit::Empty` = see-through (left out of the timeline).
- `src/bin.rs` `BinCut`: picture tracks of the sequence → `Timeline` (positions incl. the sequence's start TC); the project's other bins are read only if a clip is missing (project = nearest folder above with an .avp, Attic skipped). `jobs()` resolves each shot's middle, then `media::locate` finds the files.
- `src/media.rs`: msmFMID.pmr reader + MXF header reader copied from MediaFiles Check; `locate` uses the pmr names first, headers only for unlisted files while something is still missing. `volumes()` = /Volumes/* with "Avid MediaFiles/MXF" (UI polls every 2 s, switches per volume).
- Checked on the MediaFiles Check test lab (`~/MFC-Testlab/golden`, read only): 5 sequences, DNxHD OP-Atom frames grabbed (60 stills in 3 s); AMA sequence → "media file not on the chosen volumes" (linked files are not in Avid MediaFiles). Transitions, motion effects, multicam: unit tests only (the lab has none).
- AMA / linked media (user 2026-11-20): FILE/WINF locators are read (path, POSIX ext 0x01, UTF-8 ext 0x02); the path sits on the source mob BELOW the AMA file mob (file mob: CDCI + MSML locator, no path). `Bin::linked` returns that path with the FILE MOB's frame – the clip below carried start 1 for a 25-frame .mov (would push past the end). `bin::linked_file` accepts POSIX, file:// URLs and old "Volume:dir:file" paths. Checked: AMA sequence of the test lab, 10 stills from the .mov files (frame offset not proven, all lab clips look alike).
- Not handled yet: titles/keys on upper tracks count as visible (they resolve to media), sequence edit rate ≠ media rate is scaled but untested.

## Sheet design (user 2026-11-20, second round)
- Stills COVER their cell (scaled to fill, overhang cut around the centre) – the old fit-with-aspect left 1 px white lines at gap 0 and shifted cells; test `no_white_between_stills_at_gap_zero` uses odd sizes.
- `layout::Sheet` has `trim` (trim area of an aspect inside the paper, 12 mm room for crop marks: 3 mm off the corner, 6 mm long, 0.1 mm), `line` (width, inset from the trim edge, colour) and `headline` (text, `fonts::Face`, pt size, colour, top/bottom × left/centre/right). `Sheet::plan` places everything: headline centred on the line (without a line at the line's inset), left/right headline 8 mm in from the corner, the line breaks 2 mm around the text, the grid area keeps 2 mm clear of line and headline whatever the margin.
- Text: `src/fonts.rs` (fontdb: installed families for the menu, best face for bold/italic; missing bold = strokes widened, missing italic = slanted 0.2), drawn with ab_glyph in pt (em) sizes at the sheet's dpi.
- Third round (user 2026-11-20): margin slider 0–200 mm in 1 mm steps. Line `Pattern` (Single, Double, Thick–thin, Thin–thick, Thin–thick–thin, Two close + one apart; strands in units of the thickness, `PatternPicker` draws them). Headline hangs at one of 9 anchors of the trim area (`AnchorPicker`, same point of the text box) moved by dx/dy mm (anchor change sets ±10 / ±8 mm inward); NOT on the line by default – every strand breaks only where the text box (+2 mm) covers it (`fill_except`); top/bottom anchors keep the stills clear, middle ones lie over them. Drag in the preview on the Headline tab (frame from Rust as page fractions `head-b*`, frozen while pressed). `FontList`: std ListView, every name in its own font, ↑/↓ + letter jump (`jump-font`), reveal on init and change.
- Side column split into tabs Source / Sheet / Line / Headline (was Design) (`TabStrip`, `side-tab`); Export stays at the bottom; min height now 820. Colours: `ColorRow` (5 swatches + hex field, Rust shows what it read in the swatch square). Default orientation landscape.
- Bin mode: Sequence menu starts with "All sequences" (default) = every sequence of the bin in natural name order (`bin::natural`), shots one after the other; `BinCut.timelines`, `BinCut::shots()`. Bin-mode UI tests must not run with the 2 s volume poll – it swaps the test volumes for the user's real ones (happened twice); test bin mode with the CLI.
